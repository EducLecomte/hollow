Un projet contre le vide

Vos fichiers.

Hollow est un explorateur de fichiers et un éditeur de texte TUI, rapide, compact et entièrement écrit en Go. Un projet pour combattre le vide, dans la Guerre du pathétisme.

Installer sur Linux
$curl -sL https://raw.githubusercontent.com/EducLecomte/hollow/main/install.sh | bash
Voir le projet ↗ Installation détaillée
hollow ./mon-dossier
Pensé pour le terminal

Tout ce qu'il faut pour gérer vos fichiers.

Une interface à double panneau, l’édition plein écran, les connexions distantes et la navigation dans les archives, réunies dans un outil simple et efficace.

Explorer sans détour

Parcourez vos fichiers locaux, FTP, FTPS et SFTP, puis naviguez dans les archives .zip, .tar et .tar.gz pour en extraire le contenu.

Rester dans le flux

Éditeur intégré, double panneau et fuzzy finder : modifiez, copiez, renomez et retrouvez l’essentiel sans quitter le terminal.

Installer simplement

Un binaire Go léger et une installation d’une ligne, sur Linux amd64 et arm64.

Conçu en Go

Petit binaire.
Grande souplesse.

Hollow est compilé en un seul binaire Go : rien d’autre à installer, un terminal suffit.

# Ouvrir le répertoire courant
hollow

# Ouvrir un répertoire précis
hollow internal/app

# Éditer un fichier existant ou nouveau
hollow README.md
